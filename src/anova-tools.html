Excel · one-way ANOVA by hand

Enter Process A, Process B, Process C as headings in A1:C1. Enter the four observations per process from Topic 1 in A2:C5. Use the following cells for the calculation. Formulas use English names and comma separators.

One-way worksheet recipe · default 12 observations
CellFormulaMeaning / expected result
A8=AVERAGE(A2:A5)Mean A = 20; copy across through C8 for 24 and 27
D8=AVERAGE(A2:C5)Weighted grand mean = 23.6666667
D9=DEVSQ(A2:A5)+DEVSQ(B2:B5)+DEVSQ(C2:C5)SSW = 24
D10=COUNT(A2:A5)*(A8-$D$8)^2+COUNT(B2:B5)*(B8-$D$8)^2+COUNT(C2:C5)*(C8-$D$8)^2SSG = 98.6666667
D11=DEVSQ(A2:C5)SST = 122.6666667; should equal D9+D10
D13=COLUMNS(A1:C1)-1Between df = 2
D14=COUNT(A2:C5)-COLUMNS(A1:C1)Within df = 9
D15=D10/D13MSG = 49.3333333
D16=D9/D14MSW = 2.6666667
D17=D15/D16F = 18.5
D18=F.DIST.RT(D17,D13,D14)p ≈ 0.000648158
D19=F.INV.RT(0.05,D13,D14)5% critical F ≈ 4.2564947

DEVSQ returns the sum of squared deviations from the mean of the supplied numbers. The count-based SSG formula keeps the correct weights if the group lengths differ. Adjust the ranges to include all observations; do not convert blank padding into zeros.

Excel · Analysis ToolPak

  1. Enable Analysis ToolPak if “Data Analysis” is missing. On Windows, look under File → Options → Add-ins → Excel Add-ins → Go. On Mac, use Tools → Excel Add-ins. Menus vary by version.
  2. For one factor, choose Data → Data Analysis → Anova: Single Factor. Select A1:C5, group by columns, check labels in first row, set α=.05, and choose a new worksheet for output.
  3. Reconcile group count, sum, average and variance, then the Between Groups, Within Groups and Total rows. Match SS, df, MS, F, P-value and F crit against the lab.

  2. Map output to the design: Columns = offer (factor A); Sample = day type (factor B); Interaction = A×B; Within = cell-level error. The row labeled “Sample” is a factor, not the whole dataset.

  4. Read the interaction and cell means before reporting a single main-effect story. Do not choose “without replication” for these replicated data.
Calculate two-way ANOVA without an add-in

Keep the data in B2:C7. Put cell means at E2:F3: E2==AVERAGE(B2:B4), F2==AVERAGE(C2:C4), E3==AVERAGE(B5:B7), F3==AVERAGE(C5:C7). Here rows are B levels and columns are A levels, giving [[20,24],[26,38]]. This is the transpose of the A-row convention used in the formulas, but it represents the same cells.

Offer marginal means: E5==AVERAGE(B2:B7), F5==AVERAGE(C2:C7). Day marginal means: H2==AVERAGE(B2:C4), H3==AVERAGE(B5:C7). Grand mean: H5==AVERAGE(B2:C7).

Manual balanced two-way sums of squares
ComponentFormulaResult
SSA · offer=6*((E5-$H$5)^2+(F5-$H$5)^2)192
SSB · day=6*((H2-$H$5)^2+(H3-$H$5)^2)300
SSAB=3*((E2-E5-H2+$H$5)^2+(F2-F5-H2+$H$5)^2+(E3-E5-H3+$H$5)^2+(F3-F5-H3+$H$5)^2)48
SSE=DEVSQ(B2:B4)+DEVSQ(C2:C4)+DEVSQ(B5:B7)+DEVSQ(C5:C7)32
SST=DEVSQ(B2:C7)572

Divide SSA, SSB and SSAB each by 1; divide SSE by 8. Each F divides the relevant MS by MSE=4. For example, =F.DIST.RT(12,1,8) returns the interaction p-value ≈.008516263; =F.INV.RT(0.05,1,8) returns ≈5.317655. Use the observed F in F.DIST.RT. Keep full precision in cells and round only the display.

Python · one file, both designs

The complete example below uses ordinary Python lists. groups[i][j] indexes observation j in group i. cells[i][j][k] indexes replicate k at A level i and B level j. Python’s indices start at zero; the mathematical indices start at one. The nested loops make every sum of squares visible.

The script calculates means, SS, df, MS and F using the standard library. When SciPy is available, scipy.stats.f.sf calculates upper-tail probabilities and f.isf calculates upper-tail critical values. Without SciPy, it still runs and clearly marks p-values and critical values as unavailable. No Python code runs in this browser page.

Make one change. Double each observation’s deviation from its group or cell mean while keeping the means fixed. Predict what happens to the SS for effects, the residual SS and the F statistics, then run it. The effect SS stay fixed, residual SS becomes four times larger, and each F becomes one-quarter as large. The p-values increase.
