Excel · Analysis ToolPak workflow and diagnostics

  1. Enable Analysis ToolPak if Data Analysis is absent: Windows File → Options → Add-ins → Excel Add-ins → Go; Mac Tools → Excel Add-ins. Menus vary; some web versions require desktop Excel.
  2. Choose Data → Data Analysis → Regression. Set Input Y Range to $B$1:$B$9, Input X Range to $A$1:$A$9, check Labels, and leave Constant is Zero unchecked. Retain the intercept. Set confidence level to 95% and select a new output worksheet.
  3. Select Residuals and Residual Plots. Optionally select Line Fit Plots. Run and match Observations=8, R Square≈.964286, Adjusted R Square≈.958333 and Standard Error≈.981981. Multiple R≈.981981 is the nonnegative square root of R², not a signed slope.
  4. Match the ANOVA SS, df and MS above. “Significance F” tests the zero-slope model here. Match the coefficient estimates, standard errors, t Stat, P-value and 95% bounds. “X Variable 1” or the X header identifies the slope; “Intercept” is separate.
  5. Create an XY scatterplot with fitted values C2:C9 on the horizontal axis and residuals D2:D9 on the vertical axis. Add a horizontal zero reference. A curve suggests nonlinearity; a widening fan suggests unequal variance; isolated points deserve investigation, not automatic deletion.
  6. Plot residuals against actual collection time/order if it is available to look for dependence. This worksheet is ordered by spend, not collection time, so its row numbers cannot establish time independence. For normality, inspect a normal Q–Q plot of the residuals in appropriate software. ToolPak’s “Normal Probability Plots” option is not a substitute for a residual Q–Q diagnostic. With only eight points, diagnostics have little power; study design matters.

Exact small-sample t and F inference assumes a linear conditional mean, independent normally distributed errors and common error variance. A new-observation PI also assumes a new independent case generated under that same model. Good R² or a small p-value does not verify these assumptions.

Python · transparent algebra, optional inference library

Save and run python3 regression.py. The standard library calculates coefficients, fitted values, residuals, sums of squares, standard errors, t, F and R². If SciPy is installed, t.sf supplies two-sided coefficient p-values, t.isf the critical value, and f.sf the model upper-tail probability. Without SciPy, the script runs and explicitly marks p-values and intervals unavailable. No Python executes in this page.

The function accepts paired numeric lists or tuples, x₀ and α. It rejects missing/nonnumeric/nonfinite data, unequal lengths, fewer than three observations, constant variables and perfect or numerically near-perfect fits. These degenerate cases need separate treatment, not invented p-values. At most 10,000 observations and numeric magnitudes up to 10¹² are accepted; center or rescale poorly conditioned data.
