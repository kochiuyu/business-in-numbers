Excel + Python distribution desk

All examples below are synthetic teaching data. Python 3.10+ is required; the distribution examples also require SciPy (checked with SciPy 1.17.0). Install the dependency in your own environment with python -m pip install scipy, then save and run each script with Python. No datasets, credentials, plotting libraries, or network calls are needed by the scripts.

Choose the operation before choosing the function
QuestionSciPy methodMeaning
Exactly k, discrete Xlaw.pmf(k)P(X = k)
Up to xlaw.cdf(x)P(X ≤ x)
Above xlaw.sf(x)P(X > x), often more accurate than 1 − CDF in extreme tails

Continuous density at xlaw.pdf(x)A height, not P(X = x). Point probability is zero; probability is area.

Right-tail probability αlaw.isf(alpha)Inverse survival function; for continuous laws, the cutoff with upper-tail area α

For a continuous interval use law.cdf(b) - law.cdf(a). For integer-valued X and integer bounds a and b, an interval a ≤ X ≤ b use law.cdf(b) - law.cdf(a - 1). In discrete inverse problems the desired tail area may not be attainable exactly. A continuous quantile has the requested area, subject to numerical precision.

1 · Expectation, variance, and a revenue transform

Enter orders 0, 1, 2, 3 in A2:A5 and probabilities 0.1, 0.3, 0.4, 0.2 in B2:B5. Check =SUM(B2:B5) equals 1 and every probability is between 0 and 1. In D2 compute the mean with =SUMPRODUCT(A2:A5,B2:B5). In D3 compute variance with =SUMPRODUCT(B2:B5,(A2:A5-D2)^2); in D4 use =SQRT(D3). This is distribution variance, not the sample estimator VAR.S.

For revenue Y = 5 + 20X, =5+20*D2 gives the mean and =20^2*D3 gives variance. A fixed fee changes the mean, not the variance. More generally E[a+bX] = a+bE[X], Var(a+bX) = b²Var(X), and SD(a+bX) = |b|SD(X).

2 · Binomial, Poisson, and sampling without replacement
Exact Excel formulas for the count examples
Model and questionExcel formula
Binomial n=12, p=.25: exactly 3=BINOM.DIST(3,12,0.25,FALSE)
Binomial: at most 3=BINOM.DIST(3,12,0.25,TRUE)
Binomial: at least 4=1-BINOM.DIST(3,12,0.25,TRUE)
Binomial: 95th percentile=BINOM.INV(12,0.25,0.95)
Poisson mean=4/hour: exactly 3 in one hour=POISSON.DIST(3,4,FALSE)
Poisson: at least 6 in one hour=1-POISSON.DIST(5,4,TRUE)
Poisson: none in half an hour=POISSON.DIST(0,4*0.5,FALSE)
Hypergeometric N=40, K=8, n=6: exactly 2=HYPGEOM.DIST(2,6,8,40,FALSE)
Hypergeometric: at least 1=1-HYPGEOM.DIST(0,6,8,40,TRUE)

Excel HYPGEOM.DIST uses successes in sample, sample size, successes in population, population size, cumulative. SciPy uses hypergeom(M=40,n=8,N=6): its parameter letters differ from common textbook notation. Binomial requires a fixed number of independent trials and constant p; hypergeometric uses uniform sampling without replacement. Poisson needs a constant arrival rate and independent increments; scale its mean to the time window.

3 · Uniform, exponential, normal, and the Z table
Exact Excel formulas for continuous examples
QuestionExcel formula
Uniform [2,8]: CDF at x in A2=MAX(0,MIN(1,(A2-2)/(8-2)))
Uniform: P(3 ≤ X ≤ 5)=(5-3)/(8-2)

Exponential rate=.1/min: up to 5 minutes=EXPON.DIST(5,0.1,TRUE)
Exponential: over 15 minutes=EXP(-0.1*15)

Normal: above 504=1-NORM.DIST(504,500,4,TRUE)
Normal: 95th percentile=NORM.INV(0.95,500,4)

Parameter trap: Excel EXPON.DIST takes the rate 0.1; SciPy expon takes scale=10, the mean. Both Excel NORM.DIST and SciPy norm take standard deviation 4, not variance 16. SciPy uniform takes loc=2, scale=6, not scale=8.

Z-table workflow: Standardize with z = (x − 500)/4. The bounds become −1 and +1. A left-tail table gives Φ(1) ≈ .8413 and Φ(−1) ≈ .1587, so the interval is approximately .6826 (software gives .682689). Check the table heading: a table showing area from 0 to z gives .3413 at z=1, requiring .5 to recover the left tail. Use symmetry Φ(−z)=1−Φ(z). In a two-decimal Z table, z=1.23 uses row 1.2 and column .03. Excel equivalents are =NORM.S.DIST(1,TRUE) and =NORM.S.INV(0.95).

4 · Chi-square, t, and F reference laws

These continuous reference distributions will support inference later. Chi-square is nonnegative with one degrees-of-freedom parameter; t is symmetric with heavier tails than the standard normal; F is nonnegative with numerator and denominator degrees of freedom. Degrees of freedom must be positive. Do not swap the F parameters.

Left CDF, density, and inverse upper-tail cutoffs in Excel

t, df=9=T.DIST(2,9,TRUE)

F, df1=5, df2=10=F.DIST(2,5,10,TRUE)

Right-tail areas at those values are =CHISQ.DIST.RT(12,9), =T.DIST.RT(2,9), and =F.DIST.RT(2,5,10). A two-sided t cutoff with total α=.05 uses =T.INV.2T(0.05,9), matching t.isf(.025,9), not t.isf(.05,9). For continuous laws a right-tail α cutoff is the left-tail 1−α percentile; direct right-tail functions are preferable for tiny α.

5 · Build the chart without changing its meaning
  1. Discrete PMF: put all possible integers in column A, their PMF in B, and insert a column chart with separated bars. For Binomial(12,.25), use 0 through 12 and =BINOM.DIST(A2,12,0.25,FALSE), filled down. Label the vertical axis “Probability.” Do not use a smooth density curve.
  2. Continuous PDF: for the normal example, enter x=484, 484.25, …, 516 in column A and =NORM.DIST(A2,500,4,FALSE) in B. Insert an XY scatter chart with lines. Label axes “Fill (mL)” and “Density (per mL).” The displayed range is finite; normal tails extend beyond it.
  3. Shade an interval: add a helper column =IF(AND(A2>=496,A2<=504),B2,0). A shaded area is illustrative; calculate the exact probability with the CDF difference, not a sum of heights. A numerical area approximation needs heights multiplied by grid spacing.
  4. CDF: use TRUE instead of FALSE in the distribution formula. Continuous CDFs rise smoothly; discrete CDFs jump. For a discrete staircase, repeat each jump location with the previous and new cumulative values, then use straight XY line segments. Never smooth across discrete jumps.

For continuous models P(X=x)=0 even if the density is high. Densities can exceed 1 when their units make the support narrow. Always label units and distinguish theoretical probabilities from observed histogram frequencies.
